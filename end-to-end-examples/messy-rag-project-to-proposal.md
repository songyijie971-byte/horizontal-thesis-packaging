## 建议题目

面向企业制度文档的检索增强问答系统设计与实现

## 开题研究问题

面向企业知识管理场景中文档分散、检索效率低和答案来源难追溯等问题，本文研究并设计基于检索增强生成的知识库问答系统，以提升制度文档问答的相关性、可追溯性和系统可用性。

## 研究内容

1. 企业知识库问答场景需求分析与任务建模。
2. 文档清洗、切分、向量化和语义检索流程设计。
3. 检索增强生成问答与引用溯源机制设计。
4. 问答效果评估与系统功能、响应性能测试。

## 技术路线

文档上传 -> 文档解析 -> 文本切分 -> 向量化入库 -> 用户提问 -> 语义检索 -> 上下文构建 -> 大模型生成 -> 引用来源展示 -> 结果反馈。

## 实验计划

- 构建小规模问答评价集。
- 比较关键词检索、向量检索、RAG 问答。
- 测试 chunk size、Top-k、相似度阈值。
- 评价 Recall@k、答案相关性、引用准确性、响应时间。

## 开题风险

- 不要把 API 调用写成大模型理论创新。
- 需要补问答评价集。
- 企业文档需脱敏。
- 未上线只能写测试环境验证。
