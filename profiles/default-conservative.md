# 默认保守版 Profile

## 适用场景

适合大多数国内工科硕士论文、开题报告、中期检查和毕业答辩。

## 输出风格

- 稳健、克制、可答辩。
- 强调真实项目、本人工作量、实验验证。
- 优先使用“主要工作”“主要特色”“应用价值”，谨慎使用“创新点”。
- 不写大而空的宏观背景。
- 不把工程功能包装成理论突破。

## 推荐表达

- “面向【场景】中的【问题】，本文设计并实现了【系统/方法】。”
- “通过【功能/性能/对比/消融】实验验证了【效果】。”
- “本文工作主要体现在【场景适配/系统集成/工程优化/实验验证】。”

## 禁用表达

- 首次
- 突破性
- 颠覆性
- 国际领先
- 完全解决
- 显著优于所有方法

## 风险重点

每次输出都检查：

1. 是否虚构数据或部署效果？
2. 是否夸大创新？
3. 是否像项目说明书？
4. 是否缺少实验或测试？
5. 是否说清本人负责内容？
