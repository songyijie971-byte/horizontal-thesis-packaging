# 开题救火版 Profile

## 适用场景

用户临近开题、题目不稳、导师说太工程、研究内容散乱、技术路线说不清时使用。

## 目标

快速把项目收束成可开题版本。

## 输出优先级

1. 先定论文主线
2. 再定题目
3. 再定研究内容
4. 再定技术路线
5. 最后补实验计划和风险点

## 输出格式

```markdown
## 开题救火判断

推荐主线：

建议题目：

一句话研究问题：

三条研究内容：

技术路线：

开题最该补的材料：

导师可能质疑：

不建议写法：
```

## 风格要求

- 不展开太多背景。
- 不堆文献。
- 优先解决“题目、研究内容、技术路线、实验可行性”。
- 所有表达要能直接放进开题报告。
