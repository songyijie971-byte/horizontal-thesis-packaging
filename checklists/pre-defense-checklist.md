# 答辩前检查清单

## PPT 主线

- [ ] 3 分钟内能讲清楚研究问题。
- [ ] PPT 有问题、方法、系统、实验、总结的完整链路。
- [ ] 每页只讲一个中心观点。
- [ ] 没有大段论文正文。
- [ ] 不只展示系统截图。

## 创新点与贡献

- [ ] 创新点控制在 2 到 3 条。
- [ ] 创新点和研究内容对应。
- [ ] 创新点有实验或系统证据支撑。
- [ ] 表述稳健，没有“首次”“突破性”等夸张词。

## 本人工作量

- [ ] 能说清本人负责模块。
- [ ] 能说清每个模块输入、输出、流程。
- [ ] 能区分团队工作和个人工作。
- [ ] 能展示本人完成的代码、接口、实验或文档。

## 数据与实验

- [ ] 能说明数据来源。
- [ ] 能说明评价指标为什么这样选。
- [ ] 能说明实验环境。
- [ ] 能解释每个结果说明了什么。
- [ ] 能说明不足和后续改进。

## 高频追问准备

- [ ] 你的创新点是什么？
- [ ] 和普通工程开发有什么区别？
- [ ] 数据从哪里来？
- [ ] 为什么选这些指标？
- [ ] 有没有对比实验？
- [ ] 有没有消融实验？
- [ ] 系统是否部署？
- [ ] 你本人负责哪些工作？
- [ ] 如果没有真实部署，怎么证明有效？
- [ ] 后续如何改进？

## 演示材料

- [ ] 系统截图或演示视频准备好。
- [ ] 实验结果表准备好。
- [ ] 关键图表编号和论文一致。
- [ ] 答辩版本和论文最终版本一致。
- [ ] 备份文件准备好。
