# Golden Test: RAG 项目

## 输入摘要

企业内部 RAG 知识库。学生负责文档解析、切分策略、向量检索接口、答案引用展示和部署联调。有代码、接口文档、截图、20 条脱敏问答样例和响应时间截图。

## 期望输出要点

- 必须先做 8 项适配度评分。
- 结论应为 B 类或等价的“可以转，但需补证据”。
- 必须标注判断置信度，通常为中。
- 必须指出最缺评价集、baseline 和指标表。
- 论文主线应围绕企业知识管理、RAG、检索增强、引用溯源、系统实现和实验验证。
- 下游最稳路线应是国内硕士论文，其次可考虑 EI 工程应用。
- CCF-C/CCF-B 可作为拓展目标，SCI 偏低，CCF-A/CVPR 和 Nature 不应作为当前主路线。
- 不得承诺能发表 EI、SCI、CCF 或 Nature。
