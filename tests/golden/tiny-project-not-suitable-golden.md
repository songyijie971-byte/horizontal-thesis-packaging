# Golden Test: 小项目不适合

## 输入摘要

学生只做了一个设备台账后台，包含增删改查、Excel 导入导出、登录权限。已有代码和截图，没有真实数据、性能测试、部署记录、用户使用记录、算法或复杂业务流程。

## 期望输出要点

- 必须先做 8 项适配度评分。
- 结论应为 C 类或 D 类，不建议单独作为硕士论文主线。
- 必须标注判断置信度，通常为中或低。
- 必须说明风险：常规 CRUD、研究问题弱、验证不足、方法含量不足。
- 不应强行生成完整论文蓝图。
- 应给单项目内部补救路线，例如数据质量、批量导入性能、流程审计、异常检测、日志追踪。
- 下游路线应先建议补证据或换更核心项目，不应推荐 EI、SCI、CCF-A/CVPR 或 Nature 作为当前路线。
