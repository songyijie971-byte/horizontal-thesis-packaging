# 实验设计与系统测试参考

## 实验设计总原则

实验不是为了堆数据，而是为了支撑论文中的 claim。

每个 claim 都要对应证据：

- 方法有效性 -> 对比实验
- 模块必要性 -> 消融实验
- 参数合理性 -> 参数实验
- 系统可用性 -> 功能测试
- 系统性能 -> 性能测试
- 工程稳定性 -> 稳定性测试
- 实际价值 -> 场景案例验证

## 算法类实验

适用场景：
- 图像识别
- 目标检测
- 文本分类
- RAG 检索
- 预测模型
- 异常检测
- 调度优化

可用实验：

1. 对比实验
   - 与传统方法比较
   - 与常用模型比较
   - 与原始方案比较

2. 消融实验
   - 去掉某模块
   - 替换某算法
   - 不使用某优化策略
   - 不加入某特征

3. 参数实验
   - 学习率
   - 阈值
   - 检索数量
   - 窗口大小
   - 模型层数
   - 权重系数

4. 泛化实验
   - 不同数据集
   - 不同场景
   - 不同设备
   - 不同环境

指标：
- Accuracy
- Precision
- Recall
- F1-score
- mAP
- AUC
- RMSE
- MAE
- Top-k accuracy
- Latency

## 系统类测试

适用场景：
- 后台管理系统
- 数据平台
- 智能问答平台
- 业务管理平台
- 可视化系统

可用测试：

1. 功能测试
   - 用户登录
   - 数据录入
   - 数据查询
   - 文件上传
   - 结果展示
   - 权限控制
   - 告警推送

2. 接口测试
   - 请求是否成功
   - 返回格式是否正确
   - 异常输入是否处理
   - 接口响应时间

3. 性能测试
   - 平均响应时间
   - 最大响应时间
   - QPS
   - 并发用户数
   - CPU 占用
   - 内存占用

4. 稳定性测试
   - 长时间运行
   - 异常恢复
   - 重复任务执行
   - 数据一致性

## 机器人类实验

可用实验：

1. 路径规划实验
   - 路径长度
   - 规划时间
   - 到达时间
   - 避障成功率

2. 控制实验
   - 控制误差
   - 定位误差
   - 轨迹偏差
   - 任务完成率

3. 系统集成实验
   - 感知模块
   - 决策模块
   - 控制模块
   - 通信模块
   - 可视化模块

4. 场景验证
   - 仿真环境
   - 实际环境
   - 不同路线
   - 不同障碍物
   - 不同任务复杂度
