# 下游论文路线适配度评估

## 目标

在单项目已经完成硕士论文适配度判断后，进一步判断它后续更适合交给哪类论文写作 skill 或写作路线继续加工。此判断只表示“当前材料下的相对可行性”，不代表投稿录用概率或刊会承诺。

## 判断顺序

1. 先判断是否适合转成国内硕士论文。
2. 如果能转，再判断最可能的下游写作路线。
3. 优先评估更现实的横向硕士路线：国内硕士论文、EI 工程应用、CCF-C/CCF-B 应用或系统类论文、SCI 应用型期刊。
4. 再评估高难路线：CCF-A/CVPR、Nature/Nature-style。
5. 输出最稳路线、次优路线、暂不建议路线。
6. 对 EI、SCI、CCF-C/CCF-B、CCF-A/CVPR、Nature 等目标必须标注前置条件和主要缺口。
7. 对普通硕士横向项目，Nature 默认视为远期表达训练或叙事参考，通常不作为当前主路线。

## 路线判断维度

| 维度 | 说明 |
| --- | --- |
| 工程完整度 | 系统是否完整，有没有真实场景、部署、测试和工程闭环 |
| 方法创新强度 | 是否有新方法、改进方法、算法设计、机制设计或可解释的技术贡献 |
| 实验严谨度 | 是否有对比实验、消融实验、统计分析、性能测试或场景验证 |
| 数据可复现性 | 数据是否可公开、可脱敏、可复现实验，是否有标准数据集 |
| Baseline 强度 | 是否有合理 baseline、SOTA/经典方法对比、工程前后对比 |
| 场景价值 | 是否有明确应用价值、行业价值、科学问题或跨学科意义 |
| 写作目标 | 用户是为了毕业、工程论文、SCI 期刊、顶会还是高影响叙事 |

## 推荐等级

| 等级 | 含义 |
| --- | --- |
| 高 | 当前材料已经比较适合该路线，补常规材料即可继续 |
| 中 | 有机会，但需要补关键实验、数据或表达 |
| 低 | 当前材料明显不足，不建议作为主要路线 |
| 极低 | 与该路线要求差距很大，仅保留为远期可能 |

每次路线评估也要标注判断置信度。项目材料越少，越要把结论写成“当前材料下的保守判断”。

## 路线适配表

| 路线 | 适合情况 | 常见缺口 |
| --- | --- | --- |
| 国内硕士论文 / `sciskill` | 有本人工作量、工程模块、可验证证据，目标是开题/中期/论文/答辩 | 研究问题不清、实验不足、章节组织弱 |
| EI 工程应用 / `ei` | 工程系统完整，有应用场景、测试指标、性能或部署验证 | 方法创新弱、实验不够系统、工程价值表达不足 |
| CCF-C / CCF-B 应用或系统类 / `ccfc` / `ccfb` | 有一定算法、系统、数据处理或机器人方法改进，有比较规范的实验与 baseline | 方法创新不够强、公开数据不足、实验规模偏小、目标会议匹配度不清 |
| SCI 应用型期刊 / `sci` | 有清晰研究问题、可量化实验、可复现数据、合理对比 | 数据不可公开、baseline 弱、创新不足、实验规模小 |
| CCF-A / CVPR / `ccfa` / `cvpr` | AI/视觉/机器人感知等方向，有明显方法创新、标准数据集、强 baseline | 横向场景太工程、缺公开数据、缺 SOTA 对比、方法新意不足 |
| Nature / Nature-style / `nature` / `natureskill` | 有强科学问题、跨学科意义、高质量证据、广泛影响叙事 | 只是工程交付、证据局部、科学问题不强、泛化价值不足 |

## 输出模板

```markdown
## 下游论文路线适配度

最稳路线：国内硕士论文 / sciskill
次优路线：EI 工程应用
可作为拓展目标：CCF-C/CCF-B 应用或系统类
暂不建议：CCF-A/CVPR、Nature

| 路线 | 适配度 | 相对可行性 | 理由 | 主要缺口 | 下一步 |
| --- | --- | --- | --- | --- | --- |
| 国内硕士论文 | 高 | 最大 | 有真实项目、本人成果和可补测试 | 实验体系还不完整 | 先生成开题/论文蓝图 |
| EI 工程应用 | 中 | 有机会 | 系统完整，可做性能和应用验证 | 工程指标需补 | 补压测、接口测试、应用案例 |
| CCF-C/CCF-B 应用或系统类 | 中低 | 可作为拓展目标 | 有系统和局部方法，但还缺规范实验 | baseline、公开数据、目标会议匹配度不足 | 补对比实验、消融实验和相关工作定位 |
| SCI 应用型期刊 | 低 | 暂不稳 | 有应用问题，但实验和数据不足 | baseline、可复现数据不足 | 补对比实验和评价集 |
| CCF-A/CVPR | 极低 | 不建议 | 方法创新和标准数据集不足 | 缺 SOTA 对比 | 不作为当前目标 |
| Nature/Nature-style | 极低 | 不建议 | 科学问题和跨学科影响不足 | 缺高影响证据 | 不作为当前目标 |
```

## 重要边界

- 不要说“能发 EI/SCI/Nature”，只说“更适合走某路线”。
- 不要把国内硕士论文要求误判成 SCI/顶会要求。
- 若用户目标是毕业，优先推荐国内硕士论文路线，再给 EI、CCF-C/CCF-B、SCI 等作为可选拓展。
- 若用户目标是投稿，必须列出离目标路线还缺哪些证据和实验。
