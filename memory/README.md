# 本地记忆层

本目录用于存放用户自己的本地记忆和自我改进记录。

## 普通用户不需要手动改这里

如果你第一次使用这个 skill，还没有填写 `CUSTOMIZE.md`，Agent 会根据 onboarding 问题帮你生成本地个性化记忆。

## 文件定位

推荐本地文件：

```text
CUSTOMIZE.local.md
memory/user-context.md
memory/session-learnings.md
memory/improvement-backlog.md
```

这些文件默认不提交到 GitHub。

## 三层记忆

```text
CUSTOMIZE.md
= 开源模板，所有用户 clone 后都能看到。

CUSTOMIZE.local.md
= 用户本地一文件私有配置，覆盖 CUSTOMIZE.md。

memory/*.md
= Agent 在使用过程中沉淀的项目偏好、导师口径、常见风险和改进建议。
```

## 隐私提醒

这里可以写个人导师偏好、学校要求和项目边界，但不要提交到公开仓库。
