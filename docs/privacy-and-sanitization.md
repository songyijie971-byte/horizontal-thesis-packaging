# 隐私与脱敏指南

## 为什么需要脱敏

横向项目常涉及企业合作、甲方需求、内部系统、业务数据、设备参数和学生个人论文材料。开源前必须先脱敏。

## 不能公开的内容

- 企业真实名称
- 合同编号、金额、甲方联系人
- 内部系统地址、账号、接口 token
- 未授权截图
- 原始业务数据
- 客户信息、员工信息、设备编号
- 导师真实姓名和私人评价
- 学校内部未公开模板
- 学生论文全文或查重稿

## 推荐替换方式

| 敏感内容 | 替换写法 |
| --- | --- |
| 某真实企业名称 | 某企业 |
| 某真实园区名称 | 某园区 |
| 内部系统名称 | 某业务系统 |
| 真实客户数据 | 脱敏业务数据 |
| 真实接口地址 | 内部接口 |
| 导师姓名 | 导师 |
| 学校内部模板 | 学校模板 |

## 数据脱敏表达

推荐写法：

“本文使用来自某企业业务系统的脱敏数据，数据字段包括【字段类型】，主要用于【任务】。由于企业数据保密要求，论文中不展示原始数据内容，仅说明数据规模、字段类型和处理流程。”

## 截图处理

开源案例中的截图应避免：

- Logo
- 企业名称
- 姓名和手机号
- 设备编号
- 内网地址
- 订单号
- 真实业务数据
