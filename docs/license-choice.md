# License Choice

Before publishing this repository publicly, choose a license.

## Common options

### MIT

Use when you want others to freely use, copy, modify, publish, and distribute the project with minimal restrictions.

Good for:

- Agent skills
- Templates
- Educational tools
- Community reuse

### Apache-2.0

Similar to MIT, but includes explicit patent language.

Good for:

- Larger open source projects
- Projects expected to receive company contributions

### GPL

Use when you want derivative works to remain open source under the same license.

Good for:

- Strong copyleft projects

## Recommendation

For this kind of Agent Skill, MIT is usually the simplest choice.

If you choose MIT, add a `LICENSE` file before publishing.

## Privacy reminder

A license does not remove your responsibility to sanitize:

- enterprise data
- advisor comments
- school internal templates
- student thesis drafts
- project screenshots
