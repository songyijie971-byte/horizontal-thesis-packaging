# Profile 贡献指南

## 欢迎贡献的 profile

欢迎贡献通用、脱敏、可复用的风格 profile，例如：

- 工科硕士保守版
- 计算机应用型硕士版
- 机器人方向版
- AI 应用系统版
- 盲审安全版
- 答辩压缩版
- 开题救火版

## 不接受的内容

不要提交：

- 真实导师姓名或评价
- 学校内部未公开模板
- 企业敏感项目材料
- 未脱敏数据或实验结果
- 个人隐私信息
- 夸大、造假或鼓励虚构实验的写法

## Profile 文件格式

建议结构：

```md
# 【Profile 名称】

## 适用场景

## 输出风格

## 必须遵守

## 禁止写法

## 实验要求

## 创新点口径

## 风险检查
```

## 命名规范

- 使用小写英文和短横线。
- 名称要描述场景。

推荐：

```text
engineering-master-conservative.md
robotics-defense.md
ai-application-thesis.md
blind-review-safe.md
```

不推荐：

```text
my-teacher.md
xx-university-secret.md
super-awesome.md
```

## 贡献前检查

- [ ] 是否脱敏？
- [ ] 是否适合公开？
- [ ] 是否没有鼓励虚构数据？
- [ ] 是否没有和主 `SKILL.md` 大量重复？
- [ ] 是否能被其他学校或方向复用？
