# 简历 Bullet 示例

## 保守版

- 参与某工业设备巡检数据平台开发，负责巡检记录、设备信息与异常告警相关后端接口实现，配合前端完成页面联调，并整理接口文档与部署说明。

适用情况：证据较少、指标还没补齐、面试时需要保持稳健表达。

## 技术版

- 基于 Spring Boot、MyBatis 和 MySQL 实现设备巡检数据平台后端接口，完成巡检记录查询、异常告警查询和设备列表模块开发，并编写 Excel 巡检数据清洗脚本支持脱敏数据导入。

适用情况：投递软件开发、后端开发、平台开发岗位，且能展示代码提交、接口文档和清洗脚本。

## 面试强化版

- 负责某工业设备巡检平台中数据查询与异常告警模块的后端开发，设计巡检记录字段映射与接口返回结构，完成测试环境部署验证；后续可补充接口响应时间、测试用例通过率和数据清洗规模作为量化结果。

适用情况：准备面试深挖时使用。正式简历中只有在补充真实指标后，才把“后续可补充”改成具体数值结论。
