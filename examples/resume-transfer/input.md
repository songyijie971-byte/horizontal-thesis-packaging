项目情况：

我参与了一个企业设备巡检数据平台。系统面向某工业园区，采集设备运行日志、巡检记录和异常告警信息，支持后台管理、数据看板、异常列表、巡检记录查询和告警通知。

我主要负责：
- 后端接口开发，包括设备列表、巡检记录查询、异常告警查询；
- 数据清洗脚本，把原始 Excel 巡检记录转换成系统需要的字段；
- 部分前端页面联调；
- 写接口文档和部署说明；
- 协助项目组做了一轮现场部署验证。

技术栈：
- Java Spring Boot
- MyBatis
- MySQL
- Vue
- ECharts
- Nginx

已有证据：
- 代码仓库有我的提交记录；

缺失情况：
