# RAG 知识库问答示例

## 示例主题

面向企业制度文档的检索增强问答系统设计与实现

## 原始项目描述

企业内部有大量制度、流程、产品手册和运维文档。员工查询资料主要依赖关键词搜索和人工咨询，存在检索效率低、答案来源不明确、文档更新后知识同步不及时等问题。项目建设一个企业知识库问答系统，支持文档上传、切分、向量化、语义检索、大模型生成、引用来源展示、权限管理和后台维护。

## 推荐论文主线

面向企业知识管理场景中文档分散、查询效率低和答案来源难追溯等问题，本文设计并实现一种基于检索增强生成的知识库问答系统，通过问答效果评估和系统测试验证系统可用性。

## 研究内容

1. 企业知识库问答场景需求分析与任务建模。
2. 文档清洗、切分、向量化和索引构建流程设计。
3. 检索增强生成问答流程与引用溯源机制设计。
4. 知识库问答系统实现与问答效果、响应性能测试。

## 实验设计

- 检索实验：Recall@k、Top-k 命中率。
- 问答质量评估：答案相关性、完整性、引用准确性。
- 参数实验：chunk size、Top-k、相似度阈值。
- 系统测试：文档上传、问答接口、权限控制、响应时间。

## 风险点

- 不能把 prompt 调整写成大模型理论创新。
- 没有评价集时，需要构建小规模问答样例集。
- 企业文档需要脱敏，不能直接展示原文。
