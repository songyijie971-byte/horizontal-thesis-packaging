# 记忆更新模板

## 使用场景

当一次论文转化蓝图、开题修改、实验设计或答辩准备完成后，用本模板生成“可选记忆建议”。不要自动写入，必须先让用户确认。

## 更新原则

- 只记录可复用偏好，不记录敏感原始数据。
- 只记录用户确认过的信息，不把模型猜测写成事实。
- 本地记忆默认不提交 GitHub。
- 如果内容适合开源，记录到 `memory/improvement-backlog.md`，由用户决定是否合并。
- 默认不记录企业真实名称、导师真实姓名、未脱敏数据、项目内部地址、论文原文或答辩记录。
- 优先记录风格偏好、导师/学校口径、常见风险、输出格式偏好、下次不必重复询问的信息。
