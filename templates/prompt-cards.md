# 提示词卡片

复制一张卡片给 Agent 即可开始。默认不需要先填写学校、导师或个人背景。

## 1. 第一次判断项目能不能写

```text
我有一个横向项目，请先判断它适不适合单独转成硕士论文。请输出 8 项评分表、A/B/C/D 结论、判断置信度、最该补的 3 个材料，以及如果能写，给论文转化蓝图。

项目简介：
我负责：
已有材料：
当前阶段：
```

## 2. 项目太工程，怕像说明书

```text
这个项目工程味很重，请先判断能不能写成论文，再帮我把功能列表转成研究问题、研究内容、章节结构和实验补全清单。不要夸大创新。
```

## 3. 只有截图和代码

```text
我目前只有代码、系统截图和少量测试记录。请判断这个项目转论文的置信度，并告诉我最少还要补哪些证据，才能支撑开题或论文第五章。
```

## 4. 判断下游路线

```text
请基于这个项目的论文转化蓝图，判断后续更适合走国内硕士、EI、CCF-C、CCF-B、SCI、CCF-A/CVPR 还是 Nature/Nature-style 路线。只评估相对可行性，不要承诺发表。
```

## 5. 导师追问模拟

```text
请模拟导师或答辩老师追问：这个横向项目为什么能写成论文、创新在哪里、本人工作量是什么、实验怎么证明。请给问题、风险、建议回答和需要补的证据。
```

## 6. 交给下游论文 skill

```text
请生成论文转化交接包，方便我交给 sciskill、ei、ccfc、ccfb、sci、ccfa、cvpr、nature 或 natureskill 继续写开题、正文或答辩 PPT。请同时推荐最稳下游路线和不建议路线。
```
