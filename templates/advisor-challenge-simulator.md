# 导师追问模拟模板

当用户担心导师、盲审或答辩追问时使用。目标不是替用户编造回答，而是提前暴露风险并把每个回答绑定证据。

## 输出格式

| 追问 | 当前风险 | 建议回答口径 | 需要补的证据 |
| --- | --- | --- | --- |
| 这个项目为什么能写成论文，而不是项目说明书？ |  |  |  |
| 你的研究问题是什么？ |  |  |  |
| 创新点或主要特色在哪里？ |  |  |  |
| 本人到底负责了哪些核心工作？ |  |  |  |
| 数据从哪里来，能不能脱敏和复现？ |  |  |  |
| 实验怎么证明有效？ |  |  |  |
| 为什么不建议走更高路线，如 CCF-A/CVPR/Nature？ |  |  |  |

## 规则

- 回答必须基于用户已有材料和可补材料。
- 缺证据时写“目前不能这样答”，然后给补证据动作。
- 对普通横向项目，优先解释毕业论文稳健性，再解释 EI、CCF-C/CCF-B、SCI 等拓展可能。
- 不要把导师追问模拟写成讨好导师的话术，要写成可验证的答辩准备。
